# NC Election Atlas

Interactive precinct-level North Carolina election results, 2000–2026: general elections, primaries, runoffs, municipal elections, courts, local races and voter registration.

Open `index.html` through a web server (GitHub Pages, or `python -m http.server` locally); opening it straight from disk will not load the data files.

Basemap: © OpenStreetMap contributors, tiles from tile.openstreetmap.org (light use only; see the OSM tile usage policy).
